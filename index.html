AWS for Data & AI Teams

AWS rents storage and compute separately, each by its own meter, behind an identity system that says no by default. Six leader sessions teach a data leader to read that sentence in every proposal and every bill, with no code and no account. Eight analyst sessions build it in Python on a laptop, against a local mock of the AWS API, on 100,000 real New York taxi trips, and end in a bench that evaluates IAM policies the way AWS documents and prices queries from the AWS Price List.
